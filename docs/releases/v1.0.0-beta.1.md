# CVForge v1.0.0-beta.1 - première version à emporter

**Adapter son CV à une offre sans jamais rien inventer.** Un seul fichier, aucune installation,
rien ne sort de ton ordinateur.

## Pour l'utiliser

1. Télécharge `CVForge.exe` ci-dessous (Windows 10 / 11).
2. Double-clique dessus. Une fenêtre s'ouvre avec l'application. La fermer arrête CVForge.
3. Colle une offre d'emploi et ton CV, suis les cinq étapes, télécharge le PDF.

Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » : l'exe n'est pas
encore signé (c'est prévu). Clique sur « Informations complémentaires » puis « Exécuter quand
même ». Le code source est public dans ce dépôt : tu peux vérifier toi-même ce qu'il fait.

**Mode clé USB** : pose un fichier vide nommé `cvforge.portable` à côté de l'exe. Tes données
iront dans un dossier `data/` à côté, au lieu de `~/.cvforge/`.

## Ce que fait cette version

- **Sources** : colle ou importe (PDF / texte, lu sur ta machine) l'offre, ton CV, et en option
  ton profil LinkedIn.
- **Analyse** : ce que ton CV couvre déjà, ce que LinkedIn révèle, ce qui manque vraiment.
  Calculé sans IA. Les variantes d'un même mot se reconnaissent (déploiement / déployé).
- **Adaptation** : à la main, avec ton ChatGPT ou Claude habituel (copier-coller d'un prompt
  verrouillé : rien d'inventé), ou avec ta propre clé API. Score recalculé en direct.
- **Avant / Après** : chaque ajout doit être confirmé « vrai et prouvable » avant l'export.
  Rien ne part sans ta validation.
- **PDF et suivi** : PDF prêt à envoyer, puis « réponse reçue ? entretien ? » en trois clics,
  depuis l'Accueil à tout moment.
- **Profil et banque de preuves** : les faits de ton parcours, reliés à leurs preuves.
- **Sauvegarde** : tout dans un fichier ZIP, restaurable sur n'importe quelle machine. Ta clé
  API n'y est jamais incluse.

## Ce qui n'y est pas encore

Export Word (DOCX), vérification du format pour les logiciels de tri de CV, anonymisation
avant envoi à une IA, autres fournisseurs d'IA qu'Anthropic, préparation d'entretien. Voir la
feuille de route dans `docs/roadmap/ROADMAP.md`.

## Où vont mes données ?

Nulle part. Pas de compte, pas de serveur, pas de télémétrie. Le seul appel réseau possible
est celui que **tu** déclenches avec ta propre clé API, après avoir vu exactement ce qui part.
